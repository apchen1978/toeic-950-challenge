# 2026-11-11 題庫答案稽核

`answer-audit-2026-11-11.csv` 由 `node scripts/build-answer-audit.mjs` 產生，逐題列出 ID、Part、狀態、修正說明與題目所依據的原文摘錄。這一輪涵蓋原有 790 題與新增 39 題，共 829 題；其中 32 題有答案、選項、解析、題型或能力標籤修正。

自動測試檢查答案索引、重複選項、中文解析標示的正解字母和引號文字、題幹日期與原文，以及稽核表是否完整。原文摘錄採字詞關聯自動選句；跨文件題列出各文件的候選句。原文摘錄與結構檢查不能證明語意只有一個合理答案，出題與合併前仍應人工抽查，尤其是推論題和跨文件題。

這輪未退役題目。發現的錯誤可以修正，沒有為達退役數字而移除可用題。程式已支援 `retired: true`：新快速模考與分區練習不抽取含退役題的整組；舊作答及固定 Form 仍可讀取原題。
